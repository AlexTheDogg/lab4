# Описание геометрических функций

В проекте реализованы 11 функций в четырёх модулях. Функции принимают аргументы, возвращают результат и не выполняют ввод или вывод.

[Главная страница](../readme.md) · [Описание решения](solution_description.md) · [Протокол тестирования](test_protocol.md)

## Круг — circle.py

Исходный код: [circle.py](../circle.py). Параметр `r` — радиус. Для геометрического использования предполагается `r >= 0`; при нуле обе функции возвращают ноль. Проверка знака в этих функциях отсутствует.

| Сигнатура | Результат и формула | Тип результата | Пример |
| --- | --- | --- | --- |
| `area(r)` | Площадь круга: `π * r²` | `float` | `circle.area(1)` → `3.141592653589793` |
| `perimeter(r)` | Длина окружности: `2 * π * r` | `float` | `circle.perimeter(1)` → `6.283185307179586` |

Число π берётся из `math.pi`.

## Квадрат — square.py

Исходный код: [square.py](../square.py). Параметр `a` — сторона квадрата.

| Сигнатура | Результат и формула | Тип результата | Пример |
| --- | --- | --- | --- |
| `area(a)` | Площадь: `a²` | `int` или `float` | `square.area(8)` → `64` |
| `perimeter(a)` | Периметр: `4 * a` | `int` или `float` | `square.perimeter(8)` → `32` |
| `diagonal(a)` | Диагональ: `a * √2` | `float` | `square.diagonal(2)` → `2.8284271247461903` |

`area` и `perimeter` не проверяют знак стороны; для геометрического использования и текущих тестов предполагается `a >= 0`.

`diagonal` принимает `a >= 0`. При `a == 0` возвращает `0.0`; при `a < 0` вызывает `ValueError` с сообщением «Сторона квадрата не может быть отрицательной».

## Прямоугольник — rectangle.py

Исходный код: [rectangle.py](../rectangle.py). Параметры `a` и `b` — стороны прямоугольника.

| Сигнатура | Результат и формула | Тип результата | Пример |
| --- | --- | --- | --- |
| `area(a, b)` | Площадь: `a * b` | `int` или `float` | `rectangle.area(3, 4)` → `12` |
| `perimeter(a, b)` | Периметр: `2 * (a + b)` | `int` или `float` | `rectangle.perimeter(3, 4)` → `14` |
| `diagonal(a, b)` | Диагональ: `√(a² + b²)` | `float` | `rectangle.diagonal(3, 4)` → `5.0` |

`area` и `perimeter` не проверяют знак сторон; для геометрического использования и текущих тестов предполагается `a >= 0` и `b >= 0`.

`diagonal` использует `math.hypot`. Нулевые стороны допускаются: `diagonal(0, 4)` возвращает `4.0`, `diagonal(0, 0)` — `0.0`. Если хотя бы одна сторона отрицательна, возникает `ValueError` с сообщением «Стороны прямоугольника не могут быть отрицательными».

## Треугольник — triangle.py

Исходный код: [triangle.py](../triangle.py). Параметры `a`, `b`, `c` — три стороны.

| Сигнатура | Результат | Тип результата | Пример |
| --- | --- | --- | --- |
| `is_valid(a, b, c)` | Выполняются ли условия существования | `bool` | `triangle.is_valid(3, 4, 5)` → `True` |
| `perimeter(a, b, c)` | Сумма `a + b + c` | `int` или `float` | `triangle.perimeter(3, 4, 5)` → `12` |
| `area(a, b, c)` | Площадь по формуле Герона | `float` | `triangle.area(3, 4, 5)` → `6.0` |

Для площади сначала вычисляется полупериметр `p = (a + b + c) / 2`, затем `√(p * (p - a) * (p - b) * (p - c))`.

При недопустимых числовых сторонах `is_valid` возвращает `False`. Функции `area` и `perimeter` сначала вызывают `is_valid`, а при результате `False` вызывают `ValueError` с сообщением «Такие стороны не образуют треугольник».

```python
import triangle

print(triangle.is_valid(1, 2, 3))  # False: вырожденный треугольник
print(triangle.is_valid(1, 2, 4))  # False: сумма двух сторон меньше третьей

try:
    triangle.area(1, 2, 3)
except ValueError as error:
    print(error)  # Такие стороны не образуют треугольник
```

## Проверки функций

Тесты находятся в [test_geometry.py](../test_geometry.py). Результаты для дробных чисел сравниваются с относительным допуском `1e-10`, для нуля используется точное сравнение. Возвращаемые булевы значения проверяются через `assertIs`, ожидаемые исключения — через `assertRaises(ValueError)`.

Тесты проверяют тип исключения, но не его текст. Полная таблица входных данных и фактических результатов находится в [протоколе](test_protocol.md).
