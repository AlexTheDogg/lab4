# Лабораторная работа 4 по ИСРПО.
Данный репозиторий представляет собой набор функций для вычисления площади и периметра некоторых геометрических фигур, поиска диагонали прямоугольника, проверки треугольника на вырожденность, а также [*документацию*](docs) по проекту, В которой содержатся:
- [*история коммитов*](docs/commits_history.md)
- [*описание функций*](docs/functions.md)
- [*общее описание выполнения лабораторной работы*](docs/solution_description.md)

## Тесты.
В рамках лабораторной работы № 4 подготовлен файл [test_geometry.py](test_geometry.py), содержащий 93 автоматических модульных теста для всех 11 функций проекта. Используется стандартный модуль Python unittest; установка дополнительных библиотек не требуется. Для запуска тестов Откройте терминал в корне репозитория, где находятся test_geometry.py и четыре модуля фигур.
### Запуск тестов в корне репозитория:
#### Все тесты:
```bash
python3 -m unittest -v test_geometry
```
#### определенные тесты:
```bash
python3 -m unittest -v test_geometry.<Test_group_name>.<test_name>
```
